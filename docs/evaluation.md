## Limitations - read before interpreting these numbers

- The dataset is **synthetic** and small. Layouts are cleaner and less varied than real-world invoices, so real-world accuracy will be lower; use the numbers to compare methods and detect regressions, not as a promise.
- Scans are simulated (blur, noise, skew, contrast loss, JPEG artefacts), not physical scans.
- The `rules` baseline was written against the same family of layouts that generated the dataset, so it looks better here than it would on unseen formats. The LLM path is the intended production extractor.
- Timings depend on the machine; this run used 1 CPU core(s).
